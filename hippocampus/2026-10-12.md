# Session — 2026-10-12: birth

GriseMatter is created during a design conversation with Sam. The idea: a
brain that is just a git repo — thousands of Markdown files organized like
brain regions, plugged into an agent, getting *more precise over time*
through two loops instead of just bigger. Named after "matière grise",
following the NoireBox naming recipe (French adjective + English noun).

Decisions taken this session, recorded raw:

LEARN: A memory repo gets sharper by consolidating and pruning, not by accumulating — precision is not size.
EVIDENCE: Design session; without the two loops a "brain" folder just becomes a junkyard, accumulation only makes it bigger. The brain metaphor only works if consolidation (hippocampus→cortex) and synaptic pruning are first-class mechanisms.
TYPE: semantic

LEARN: How to put GriseMatter to sleep: run sleep/consolidate.py on the latest hippocampus log, review the generated proposals, merge them, then run sleep/consolidate.py --index to refresh INDEX.md.
EVIDENCE: This exact procedure was executed during the birth session on this very log — proposals were generated, merged, and the INDEX maps refreshed.
TYPE: procedural

LEARN: The cortex is only ever written during sleep, never live — merging a reviewed proposal is the sleep event.
EVIDENCE: Design decision recorded in brainstem/core.md; mirrors offline hippocampus→neocortex consolidation and makes every memory write a reviewable diff instead of a silent mutation.
TYPE: semantic

LEARN: Confidence starts at 0.3, grows by 0.1 per re-encounter, and never-hit notes decay.
EVIDENCE: Chosen as the reinforcement scheme (sleep/SCHEMA.md); mirrors synaptic strengthening and pruning, and caps unfounded rumors at 0.3.
TYPE: semantic
